# ☕ Nanna Bengaluru — Curated Cafe & Workspace Finder

An interactive web application to discover specialty coffee roasters, heritage filter kaapi spots, and remote-work-friendly cafes across Bengaluru.

## ✨ Features
- **Multi-Faceted Search & Filtering:** Filter by neighborhood (Indiranagar, Koramangala, Church Street, Jayanagar, Whitefield, Malleshwaram, HSR Layout), vibe tags (*Work-Friendly*, *Fast Wi-Fi*, *Filter Kaapi*, *Pet-Friendly*, etc.), and live keyword search.
- **IST-Aware Open Status:** Automatically calculates whether each cafe is currently open or closed using Indian Standard Time (`Asia/Kolkata`).
- **Interactive Bengaluru Map:** Powered by **Leaflet.js** and **OpenStreetMap** with synchronized markers and detail modals.
- **Persistent Bookmarks:** Save favorite spots locally via `localStorage`.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Properties & Responsive Grid), Vanilla JavaScript (ES6 Modules)
- **Mapping:** Leaflet.js + OpenStreetMap Tiles
